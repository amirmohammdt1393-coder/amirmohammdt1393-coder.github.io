# میزبان ۲۴

**اجرای ۲۴ ساعتهٔ رایگان فایل‌های پایتون — بدون سرور، بدون هزینه، بدون دامنه.**

آدرس سایت: https://amirmohammdt1393-coder.github.io

## چطور کار می‌کند؟

- فایل‌های `bots/*.py` روی **GitHub Actions** (ماشین مجازی ایزوله و یک‌بارمصرف) اجرا می‌شوند.
- هر چرخه حدود ۵٫۷ ساعت است و در پایان، چرخهٔ بعدی خودکار «زنجیر» می‌شود → پوشش تقریباً کامل ۲۴/۷.
- `watchdog` هر ۳۰ دقیقه چک می‌کند و اگر موتور اجرا مرده باشد، آن را دوباره بالا می‌آورد.
- وضعیت زنده و لاگ‌ها هر ۱۰ دقیقه در `runtime/` ثبت می‌شود و داشبورد دقیقاً همان را نشان می‌دهد — هیچ چیز نمایشی یا جعلی نیست.

## کنترل

- `runtime/control.json` با `{"stop_all": true}` → توقف واقعی همهٔ پروسه‌ها (SIGTERM/SIGKILL).
- اضافه‌شدن فایل به `bots/` → استقرار زنده تا ۶۰ ثانیه بعد (بدون نیاز به ری‌استارت).
- حذف فایل از `bots/` → حذف ربات و بستن پروسهٔ فعال.
- برای وابستگی‌ها: `bots/requirements.txt` در ابتدای هر چرخه نصب می‌شود.

## محدودیت‌ها (شفاف و بدون تعارف)

- مخزن باید **Public** بماند تا Actions برای مخازن عمومی رایگان و نامحدود باشد → پس لاگ‌ها عمومی‌اند؛ هیچ رمز، توکن یا کلیدی را در خروجی ربات چاپ نکن.
- رمزها را از **Settings → Secrets and variables → Actions** اضافه کن و در کد با `os.environ["نام"]` بخوان.
- بین چرخه‌ها وقفهٔ چندثانیه‌ای و در فشار سنگین گاهی چند دقیقه تأخیر طبیعی است.
- منابع هر چرخه: حداکثر ۲ هستهٔ CPU و ~۷ گیگابایت رم.
